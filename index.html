About this directory

This static index makes primary-source material easier to discover. It covers agent runtimes, agent and tool safety, retrieval-augmented generation, reasoning research, model evaluation, and developer utilities. Some linked projects are experimental and should not be assumed production-ready. Repository descriptions are editorial summaries; documentation URLs are transcribed from upstream sitemaps, not republished copies of their content.

QUICK ANSWERS / 002

Frequently asked questions

What is Pro-GenAI?

Pro-GenAI is a GitHub organization publishing public AI research repositories, developer tools, and supporting documentation. Visit its main website for the curated showcase.

Where is the source code?

Every project above includes a direct link to its public repository under github.com/Pro-GenAI. Check each repository's README, license, and current status before using it.

Where can I find agent documentation?

The Agent-RT section links to runtime guides, installation, architecture, and reference pages. Agent Action Guard links to tool safety documentation and articles.

Where are the engineering checklists?

The Awesome Checklists entry links to AI, backend, frontend, and shared checklists as well as review and development references.
